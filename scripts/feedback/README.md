# 의견 게시판 서버 설정

`/feedback/` 페이지는 구글 스프레드시트 + Apps Script 웹 앱에 글을 저장한다. 별도 서버가 없다.
`scripts/`는 배포 산출물에 포함되지 않으므로 `Code.gs`는 공개 사이트에 올라가지 않는다.

## 처음 한 번

1. 운영자 구글 계정의 드라이브에서 새 스프레드시트를 만든다 (예: `널스메이트 의견 게시판`).
2. **확장 프로그램 → Apps Script**를 열고 `Code.gs` 내용을 통째로 붙여 넣은 뒤 저장한다.
3. **배포 → 새 배포** → 유형 **웹 앱**, 실행 **나**, 액세스 **모든 사용자** → 배포. 처음엔 권한 승인 창이 뜨는데 허용한다.
4. 나온 `https://script.google.com/macros/s/.../exec` 주소를 `feedback/index.html`의 `const API = ""`에 넣는다.
5. 페이지에서 글을 하나 써 보면 시트에 `글` 탭이 생기고 그 글이 들어간다.

## 운영

| 칸 | 용도 |
| --- | --- |
| 답변 | 적으면 페이지에 "널스메이트 팀" 답변으로 보인다. 답변시각은 자동 기록 |
| 공개 | `N`이면 페이지에서 숨긴다. 부적절한 글은 행을 지우지 말고 `N`으로 |

- 승인 후 공개로 바꾸려면 `Code.gs`의 `REQUIRE_APPROVAL`을 `true`로.
- `Code.gs`를 고친 뒤에는 **배포 → 배포 관리 → 수정 → 새 버전**으로 다시 배포해야 반영된다. 새 배포를 만들면 주소가 바뀌니 기존 배포를 수정한다.
